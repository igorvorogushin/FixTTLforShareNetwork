# Сайт TTL Fix

Одна статическая страница: скриншот, ссылка на GitHub и кнопки скачивания.

## Запуск локально

```sh
python3 web/serve.py
```

Откройте `http://localhost:8080`. Кнопки скачивания локально не работают — сборки лежат только на сервере.

## Публикация

Скрипты деплоя хранятся локально в `deploy/` и не попадают в репозиторий (см. `.gitignore`).
