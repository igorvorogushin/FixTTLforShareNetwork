# TTL Fix для macOS

Небольшое нативное приложение, которое повторяет логику `ttl-fix.command`:

- показывает IPv4 TTL и IPv6 Hop Limit;
- выставляет оба значения на `65`;
- проверяет результат;
- позволяет вернуть стандартное значение `64`.

Изменения системные и действуют только до следующей перезагрузки Mac. При применении macOS покажет штатное окно с запросом пароля администратора.

## Открыть и собрать в Xcode

1. Откройте `TTLFix.xcodeproj` в Xcode.
2. В верхней панели выберите схему **TTL Fix** и **My Mac**.
3. Нажмите **Run** (⌘R) — Xcode соберёт и запустит приложение.

Для установочной версии: **Product → Archive**, затем в Organizer выберите **Distribute App → Copy App**. Полученный `.app` можно упаковать в DMG через Finder (Файл → Новое окно Finder → Файл → Новая папка с приложением → Дисковая утилита).
